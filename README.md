## Project Description
Coffee Everyday is a web-based Point of Sale (POS) system for our Integrative Programming subject. It helps manage simple daily coffee shop operations like taking customer orders, applying discounts (Senior, PWD, and Student), tracking active order status in the kitchen, and generating receipts or daily sales reports. 

## Main Features
Role-Based Access Control (RBAC): Distinct interfaces and privileges for **Staff** (order processing and kitchen queue management) and **Manager** (menu item additions, price updates, sales summary printing, and history clearing).
Interactive Product Catalogue & Menu Management: Dynamic search filtering, variant switching (e.g., Hot or Iced options), and manager controls to add, edit, or delete items.
Smart Basket & ID-Based Discounts:** Automated calculation of subtotals, grand totals, and special category discounts (Senior Citizen/PWD and Student ID).
Kitchen Order Routing: Real-time tracking of active orders moving through Preparing, Ready for Pickup, and Completed.
Thermal Printing Support: Built-in receipt and daily sales report modals optimized for thermal printing via custom CSS print media queries.

## Technologies Used

Icons: Lucide Icons library
